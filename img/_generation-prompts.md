# LINEN CLOUD 画像生成プロンプト一覧(NanoBanana用)

日奈子さんがNanoBanana(Google AI Studio「Nano Banana 2」無料枠など、いつもお使いのツール)で
1点ずつ生成 → ダウンロード → 下記の**保存先パス**にその**ファイル名のまま**上書き保存すれば、
プレースホルダーと自動的に差し替わります(index.html/CSS側は既にこのファイル名を参照済み)。

**全体方針**(プロンプトを打つ前に一度読んでください)
- 子供の顔写真は一切使わない。着用カットは**後ろ姿・手元・足元・逆光シルエットのみ**
- 配色: ベース`#FAF7F2` / サブ`#A9B79C` / アクセント`#D6A99D` / ダーク`#5C5347`(北欧ナチュラルトーン)
- 1枚につき2〜3回の作り直しが出るのは正常。気に入るまで微調整してOK
- 実写系とイラスト系でトーンが混ざらないよう、イラストは差し色用途に限定
- 生成後は`img/photo-credits.md`(このファイルと同じフォルダの雛形)に出所を記録してください

必須は実写12点(1〜12)。イラスト3点(13〜15)は今回のHTML/CSSではまだ未使用の
「余白があれば使う」予備枠なので、後回しでも進行に支障はありません。

## 画像が揃ったあとの残作業チェックリスト

画像(最低でも実写12点)が`img/`に揃ったら、以下の順で進めます。
日奈子さんご自身で進めても、ここまで済んだ状態で改めて声をかけていただいても、
どちらでも大丈夫です。

- [ ] 1. `img/photo-credits.md`に出所記録を記入したか確認
- [ ] 2. プレースホルダー生成用の`_gen_placeholders.py`をリポジトリから削除(納品物に含めない、SUNNYSIDE運用踏襲)
- [ ] 3. ローカルサーバー(`python3 _nocache_server.py`)でデスクトップ表示を再確認 — 特にHero/Craft/Detailsの画像アスペクト比が実際のレイアウトと合っているか
- [ ] 4. Playwrightでモバイル(390px)・タブレット(768px)を再確認 — 画像差し替えで縦横比が変わるとレイアウトが崩れる場合があるため必須
- [ ] 5. コンソールエラーがないか確認(画像404など)
- [ ] 6. `git add -A && git commit`(画像差し替えの意図を明記したメッセージで)
- [ ] 7. GitHubリポジトリ作成 → push(未作成の場合はここで新規作成)
- [ ] 8. Vercelに接続 → デプロイ(プロジェクト名は`cove-linen-cloud`を予定)
- [ ] 9. 本番URLを実ブラウザで開いて最終確認、日奈子さんへ公開URL・リポジトリURLを報告
